Introduction to demofit

library(demofit)
library(forecast)
library(ggplot2)

1. Introduction

The demofit package provides a unified framework for fitting parametric mortality curves and forecasting mortality rates with stochastic models.

The package implements multiple mortality curves and stochastic mortality models with a consistent interface and common S3 methods.

2. Preparing mortality data

For mortality curves, demofit accepts mortality rates in vector form.

For stochastic mortality models, demofit accepts mortality data in matrix form. Rows represent calendar years and columns represent ages.

The function mortalitymatrix() converts mortality data in data frame or demogdata format into the required numeric matrix format.

3. Mortality curve fitting

The function MC() provides a unified interface for fitting parametric mortality curves.

# generate synthetic mortality rates in vector form
x <- 60:89
set.seed(123); m <- 0.0000082*exp(0.10771*c(60:89)+rnorm(30,0,0.1))
# fit Gompertz curve to mortality rates
fit <- MC(x=x,m=m,curve="gompertz")
# print estimated parameters
coef(fit)
##            B            C 
## 9.803215e-06 1.052498e-01
# plot fitted Gompertz curve
plot(fit)

The fitted Gompertz curve closely follows the underlying mortality pattern.

5. Prediction intervals

Under the Gaussian assumption, the code below produces the 95% prediction intervals under the Lee-Carter model.

Under the Poisson assumption, the code below produces the 95% prediction intervals under the Lee-Carter model via residuals bootstrapping.

0.0336,0.0323,0.0313,0.0295,0.0282,0.0265,0.024,0.0226,0.0219,0.0183)

-5.18,-5.64,-6,-6.51,-6.91,-6.9,-8.32,-8.53,-9.69,-9.31)
set.seed(123)

75146,70559,65972,60898,55623,50522,47430,45895,41443,34774,
30531,27754,25105,22271,19437,16888,14458,12146,10038,7994),30,30,byrow=TRUE)
D <- round(E*M)
# fit Poisson Lee-Carter model to mortality data
fit <- PLCS(x=x,D=D,E=E,h=30,jumpoff=2)
a <- fit$alpha; b <- fit$beta; k <- fit$kappa
fv <- E*exp(matrix(a,nrow=30,ncol=30,byrow=TRUE)+outer(k,b))
res <- (D-fv)/sqrt(fv)
Mf <- forecast::forecast(fit)
# perform residuals bootstrapping using Pearson residuals
Msim <- array(NA,c(30,30,100))
for (z in 1:100) {
temp <- matrix(sample(res,900,replace=TRUE),nrow=30,ncol=30,byrow=TRUE)
pseudo <- pmax(round(temp*sqrt(fv)+fv,0),0)
model <- PLCS(x=x,D=pseudo,E=E,h=30,jumpoff=2)
bb <- model$beta; kk <- model$kappa
kkf <- simulate(auto.arima(tsclean(kk)),nsim=30)
Msim[,,z] <- exp(matrix(log(D[30,]/E[30,]),30,30,byrow=TRUE)+matrix(bb,30,30,byrow=TRUE)*(matrix(kkf,30,30,byrow=FALSE)-matrix(kk[30],30,30,byrow=FALSE)))
}
u <- apply(Msim[,6,],1,quantile,probs=0.975)
l <- apply(Msim[,6,],1,quantile,probs=0.025)
# plot forecasting results
plot(c(1991:2020),log(D[,6]/E[,6]),xlab="year",ylab="log death rate at age 65",xlim=c(1991,2050),ylim=c(-6,-3.5),type="l")
lines(c(2021:2050),log(Mf[,6]),lty=2)
lines(c(2021:2050),log(u),lty=3)
lines(c(2021:2050),log(l),lty=3)
legend("topright",legend=c("observed","forecast","interval"),lty=c(1,2,3),bty="n",cex=0.8)

6. Advanced features

The functions ENS() and ENI() generate ensemble forecast and ensemble interval forecast of mortality rates.
